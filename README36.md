# Day 36 – Probability Fundamentals

## Veda Technology Data Science Internship

### Overview
This project explores basic probability concepts using Python and NumPy. It demonstrates real-world examples such as coin tosses and dice rolls through random simulations.

### Objectives
- Understand basic probability calculations.
- Simulate random events using NumPy.
- Calculate theoretical and experimental probability.
- Compare probability values through simulations.
- Observe how experimental probability approaches theoretical probability as the number of experiments increases.

### Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

### Tasks Performed
1. Calculated basic probabilities using favorable outcomes and total outcomes.
2. Simulated 1000 coin tosses.
3. Simulated 1000 dice rolls.
4. Calculated experimental probabilities.
5. Compared theoretical and experimental probability.
6. Created a convergence graph to visualize probability results.

### Key Learnings
- Probability represents the likelihood of an event.
- Theoretical probability is calculated mathematically.
- Experimental probability is calculated using actual observations.
- Increasing the number of simulations generally makes experimental probability approach theoretical probability.

Successfully completed Day 36 – Probability Fundamentals by implementing probability calculations and random event simulations using Python and NumPy.

# Day 13: NumPy Random Sampling

## Objective
To understand random data generation and sampling using NumPy, and learn how random seeds help produce reproducible results in data science experiments.

## Tools Used
- Python
- NumPy
- Google Colab

## Topics Covered
- Generating random integers using `np.random.randint()`
- Generating random floating-point numbers using `np.random.rand()` and `np.random.uniform()`
- Selecting random samples from arrays using `np.random.choice()`
- Setting random seeds using `np.random.seed()`
- Understanding reproducibility in random experiments
- Creating small simulated datasets
- Performing random sampling on student marks data

## Tasks Performed
- Generated random integers and floating-point numbers.
- Selected random samples from NumPy arrays.
- Demonstrated reproducible random outputs using a fixed seed.
- Created and analyzed a simulated dataset.

## Key Learnings
- NumPy provides useful functions for random data generation.
- Random sampling is helpful in data analysis and experimentation.
- Setting a random seed helps reproduce results.
- Random data generation is useful for simulations and testing.

## Conclusion
This task helped me understand NumPy random sampling, random number generation, and reproducibility, which are important concepts in data science.

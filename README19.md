# Day 19: Duplicate Records and Data Validation

## 📌 Project Overview
This task focuses on identifying duplicate records, removing unwanted duplicates, and performing data validation checks using Python and Pandas.

## 🎯 Objective
- Identify duplicate rows in a dataset.
- Remove unwanted duplicate records.
- Detect invalid or inconsistent data.
- Validate records using predefined conditions.
- Improve overall data quality before analysis.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Google Colab / Jupyter Notebook

## 📚 Concepts Covered
- `duplicated()` to identify duplicate records
- `drop_duplicates()` to remove duplicates
- `isnull()` to check missing values
- Boolean indexing for validation
- Checking valid age ranges
- Detecting blank names and negative purchase amounts
- Verifying unique customer IDs
- Comparing records before and after cleaning

## 💻 Tasks Implemented

### 1. Duplicate Record Analysis
- Identify duplicate rows.
- Count duplicate records.
- Check for repeated customer IDs.

### 2. Data Cleaning
- Remove exact duplicate rows.
- Filter records containing invalid values.
- Remove records with blank customer names.
- Check and validate customer ages.
- Identify negative purchase amounts.
- Keep customer IDs unique.

### 3. Data Validation
The dataset is checked for:
- Missing values
- Blank names
- Invalid age values
- Negative purchase amounts
- Duplicate customer IDs
- Appropriate data types

### 4. Before-and-After Comparison
- Compare the number of records before and after duplicate removal.
- Count records remaining after validation.
- Verify the final dataset using validation conditions.

## 📈 Learning Outcomes
Through this task, I learned how to identify duplicate records, clean inconsistent data, apply validation rules, and verify data quality using Pandas.

## ✅ Conclusion
Duplicate detection and data validation are important steps in data preprocessing. They help improve dataset reliability and prepare data for further analysis and machine learning.

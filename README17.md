# Day 17: Filtering and Sorting DataFrames

## 📌 Project Overview
This task focuses on filtering rows and sorting data in a Pandas DataFrame using Python. It demonstrates how to retrieve specific records based on conditions and arrange data in ascending or descending order.

## 🎯 Objective
- Learn how to filter DataFrame rows using conditions.
- Apply multiple Boolean conditions.
- Sort records in ascending and descending order.
- Analyze filtered records using basic statistical operations.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Google Colab / Jupyter Notebook

## 📚 Concepts Covered
- Boolean indexing
- Conditional filtering
- AND (`&`) and OR (`|`) operators
- `sort_values()` method
- Sorting by multiple columns
- `groupby()` and `value_counts()`
- Mean, maximum, and record counting

## 💻 Tasks Implemented

### 1. Filtering Examples
- Filter employees based on salary.
- Select employees from a specific department.
- Filter employees by age.
- Select employees based on work experience.
- Apply multiple conditions using AND.
- Apply multiple conditions using OR.

### 2. Sorting Examples
- Sort salaries in ascending order.
- Sort salaries in descending order.
- Sort employees by age.
- Sort employees by experience.
- Sort by multiple columns.
- Arrange employee names alphabetically.

### 3. Data Analysis
- Count filtered employee records.
- Calculate average salary.
- Find the highest salary.
- Display filtered records in descending salary order.
- Calculate department-wise average salary.
- Count employees in each department.

## 🔍 Key Learning
- Filtering helps retrieve records that meet specific conditions.
- Boolean operators allow multiple conditions to be combined.
- `sort_values()` organizes data based on one or more columns.
- `groupby()` helps summarize data by category.

## 📈 Learning Outcomes
After completing this task, I improved my understanding of Pandas DataFrame filtering, sorting, and basic data analysis. These techniques help make datasets easier to explore and interpret.

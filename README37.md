# Day 37 – Sampling and Random Variables

## Veda Technology Data Science Internship

### Overview
This project focuses on understanding sampling techniques and random variables using Python. The Iris dataset is used to perform random sampling, repeated sampling, and statistical comparisons.

### Objectives
- Understand how random samples are selected.
- Perform random and repeated sampling.
- Compare sample statistics with population statistics.
- Understand sampling variation.
- Simulate random variables using numerical experiments.

### Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

### Dataset
**Iris Dataset**

The Iris dataset contains 150 observations with four numerical features and three flower species.

### Tasks Performed
1. Loaded and explored the Iris dataset.
2. Calculated population mean, median, and standard deviation.
3. Generated random samples from the dataset.
4. Performed repeated sampling and calculated sample means.
5. Compared population statistics with sample statistics.
6. Visualized sampling variation using a histogram.
7. Simulated 1000 dice rolls as a random variable experiment.

### Key Learnings
- Population represents the complete dataset.
- Sampling selects a subset of observations from a population.
- Repeated sampling helps understand sampling variation.
- Sample statistics can differ from population statistics.
- Random variables represent numerical outcomes of random experiments.

### Conclusion
Successfully completed Day 37 by implementing random sampling, repeated sampling, statistical comparisons, and random variable simulations using Python.

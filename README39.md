# Day 39 – Data Science Notebook and README

## Project Overview
This project focuses on performing a complete beginner-level data science workflow using the Titanic dataset. It includes data loading, cleaning, exploration, visualization, and drawing meaningful conclusions.

## Objective
To develop professional habits for documenting and presenting data science work through a well-structured Jupyter Notebook.

## Dataset Description
- **Dataset:** Titanic Dataset
- **Source:** Data Science Dojo GitHub Dataset
- **Records:** Passenger information from the Titanic
- **Important Features:** PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, and Embarked.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook
- GitHub

## Tasks Performed

1. Imported the required Python libraries.
2. Loaded the Titanic dataset.
3. Explored dataset structure and statistical summaries.
4. Identified and handled missing values.
5. Removed duplicate records.
6. Performed exploratory data analysis (EDA).
7. Analyzed survival rates by gender and passenger class.
8. Visualized age and survival distributions.
9. Created a correlation heatmap.
10. Generated key findings and conclusions.

## Key Findings
The notebook explores:
- Overall passenger survival rate.
- Survival differences between male and female passengers.
- Survival patterns across passenger classes.
- Age distribution of passengers.
- Relationships between numerical variables.

The exact findings and percentages are calculated directly in the notebook.

## Conclusion
This project demonstrates the basic data science workflow, from loading and cleaning raw data to exploring patterns and presenting findings through visualizations.

## Output
- A clean and organized Jupyter Notebook.
- Data visualizations and statistical summaries.
- A cleaned Titanic dataset CSV file.
- Key findings and conclusions.

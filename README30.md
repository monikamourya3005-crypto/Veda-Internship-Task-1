# Day 30: Descriptive Statistics

## 📌 Project Overview
This project focuses on calculating and interpreting descriptive statistics using Python, Pandas, and NumPy. It summarizes numerical data and helps understand its distribution and variability.

## 🎯 Objectives
- Calculate mean, median, and mode.
- Understand range, variance, and standard deviation.
- Calculate quartiles and percentiles.
- Interpret statistical results.
- Build a foundation in statistics for Data Science.

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Google Colab / Jupyter Notebook

## 📊 Tasks Performed
- Created a sample dataset containing numerical variables.
- Calculated descriptive statistics using `describe()`.
- Computed mean, median, and mode.
- Calculated range, variance, and standard deviation.
- Analyzed quartiles and percentiles.
- Compared mean and median.
- Prepared a final statistical summary.

## 📚 Key Concepts
- **Mean:** Average value of the data.
- **Median:** Middle value of the dataset.
- **Mode:** Most frequently occurring value.
- **Range:** Difference between maximum and minimum values.
- **Variance:** Measures how spread out data values are.
- **Standard Deviation:** Measures the dispersion of data.
- **Quartiles and Percentiles:** Help understand data distribution.

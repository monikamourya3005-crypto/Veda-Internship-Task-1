# Day 40 – Mini Data Science Project

## Project Title
Titanic Survival Analysis and Prediction

## Project Overview
This is a beginner-level end-to-end Data Science project using the Titanic dataset. The project analyzes passenger information, identifies survival patterns, performs data visualization, and builds a basic Machine Learning model to predict passenger survival.

## Problem Statement
Analyze Titanic passenger data to understand the factors affecting survival and build a basic model to predict whether a passenger survived.

## Objective
Apply the data science skills learned throughout Level 1 to solve a complete data science problem.

## Dataset Description
- **Dataset:** Titanic Dataset
- **Source:** DataScienceDojo GitHub Repository
- **Target Variable:** Survived
- **Features:** Passenger Class, Gender, Age, Family Members, Fare, and Embarked Location.

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Project Workflow

1. Data Collection and Loading
2. Data Cleaning and Preprocessing
3. Statistical Analysis
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Correlation Analysis
7. Feature Selection
8. Train-Test Split
9. Logistic Regression Model
10. Model Evaluation
11. Key Findings and Conclusions

## Key Findings
The project investigates:
1. Overall passenger survival rate.
2. Survival rate differences between male and female passengers.
3. Survival patterns across passenger classes.
4. Passenger age distribution.
5. Survival rate according to family size.
6. Machine Learning model accuracy.

Exact values and findings are calculated in the notebook.

## Machine Learning Model
- **Algorithm:** Logistic Regression
- **Target:** Passenger Survival
- **Evaluation:** Accuracy, Confusion Matrix, and Classification Report.

## Conclusion
This project demonstrates a complete beginner-level Data Science workflow, from loading and cleaning data to exploratory analysis, visualization, and introductory Machine Learning.

It helped develop practical experience in analyzing real-world data and presenting meaningful insights.

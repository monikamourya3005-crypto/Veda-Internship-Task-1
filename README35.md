# Day 35 – Classification Introduction

## Veda Technology | Data Science Internship

### Overview
This project focuses on building a beginner-friendly Classification Model using Python and Scikit-learn. The model learns from input features and predicts the appropriate categories.

### Objective
To understand the basic workflow of supervised classification, including data preparation, model training, testing, prediction, and accuracy evaluation.

### Tools & Technologies
- Python
- Pandas
- Scikit-learn
- Google Colab / Jupyter Notebook

### Dataset
**Iris Dataset**

The Iris dataset contains flower measurements and three flower species:
- Setosa
- Versicolor
- Virginica

### Tasks Performed
1. Loaded and explored the dataset.
2. Separated input features (X) and target variable (y).
3. Split the dataset into training and testing sets.
4. Built a classification model using Scikit-learn.
5. Generated predictions on test data.
6. Calculated model accuracy.

### Algorithm Used
Logistic Regression

### Expected Deliverables
- A trained classification model.
- Train-test split implementation.
- Predictions on test data.
- Basic accuracy calculation.

### Learning Outcomes
- Understood supervised classification.
- Learned how to use Scikit-learn classifiers.
- Practiced train-test splitting.
- Learned how to evaluate classification accuracy.

### Conclusion
This task provided practical experience with the basic classification workflow and helped build a foundation for understanding machine learning algorithms.

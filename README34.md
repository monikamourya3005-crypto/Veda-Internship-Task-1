# Day 34: Linear Regression Introduction

## Veda Technology – Data Science Internship

### Project Overview
This project focuses on building a simple Linear Regression model using Python and Scikit-learn.

Linear Regression is a supervised machine learning algorithm used to predict continuous numerical values by identifying the relationship between input features and a target variable.

### Objective
- Understand the basic concept of Linear Regression.
- Load and explore a dataset.
- Select input features and target variables.
- Train a Linear Regression model.
- Make predictions on unseen test data.
- Evaluate model performance using regression metrics.
- Visualize the regression relationship.

### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

### Dataset
**Diabetes Dataset – Scikit-learn**

The built-in Diabetes dataset from Scikit-learn was used for this task.

- Input Feature: BMI
- Target Variable: Diabetes Progression
- Total Samples: 442

### Tasks Performed
1. Imported the required Python libraries.
2. Loaded and explored the Diabetes dataset.
3. Checked dataset information and missing values.
4. Selected BMI as the input feature and Diabetes Progression as the target.
5. Split the dataset into 80% training and 20% testing data.
6. Created and trained a Linear Regression model.
7. Extracted the model coefficient and intercept.
8. Generated predictions on test data.
9. Visualized the regression line.
10. Compared actual and predicted values.

### Model Evaluation Metrics
The model was evaluated using the following metrics:

- **MAE (Mean Absolute Error):** Measures the average absolute prediction error.
- **MSE (Mean Squared Error):** Measures the average squared prediction error.
- **RMSE (Root Mean Squared Error):** Represents the square root of MSE.
- **R² Score:** Measures how well the model explains variations in the target variable.

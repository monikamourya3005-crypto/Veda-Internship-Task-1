# Day 12: NumPy Aggregations and Statistics

## Objective
To develop basic numerical analysis skills using NumPy aggregation and statistical functions.

## Tools Used
- Python
- NumPy
- Google Colab

## Topics Covered
- Calculating sum and mean using NumPy
- Finding median, minimum, and maximum values
- Calculating standard deviation and variance
- Performing row-wise and column-wise analysis using `axis=0` and `axis=1`
- Comparing statistical results across different subjects
- Analyzing student performance data
- Interpreting numerical analysis results

## Dataset Description
A sample student performance dataset containing marks in three subjects:
- Python
- Mathematics
- Statistics

The dataset is represented as a two-dimensional NumPy array.

## Functions Used
- `np.sum()` – Calculates the sum of array elements
- `np.mean()` – Calculates the average
- `np.median()` – Finds the median value
- `np.min()` – Returns the minimum value
- `np.max()` – Returns the maximum value
- `np.std()` – Calculates standard deviation
- `np.var()` – Calculates variance
- `np.argmax()` and `np.argmin()` – Identify the positions of maximum and minimum values

## Deliverables
- Examples of at least seven aggregation functions
- Statistical analysis of a numerical dataset
- Row-wise and column-wise calculations
- A short interpretation of the results

## Key Learning Outcomes
This task helped develop practical skills in numerical data analysis, statistical calculations, and summarizing datasets efficiently using NumPy.

## Conclusion
NumPy aggregation and statistical functions provide an efficient way to analyze numerical data and understand patterns in student performance.

# Day 20: Data Types and Type Conversion

## 📌 Project Overview
This task focuses on inspecting DataFrame data types and converting columns between strings, integers, floats, Boolean values, and dates using Python and Pandas.

## 🎯 Objective
- Inspect the data types of DataFrame columns.
- Convert columns to appropriate data types.
- Handle invalid values during numeric conversion.
- Prepare a cleaned dataset for accurate data analysis.

## 🛠️ Tools and Technologies
- Python
- Pandas
- Google Colab / Jupyter Notebook

## 📚 Concepts Covered
- `dtypes` and `info()` for data type inspection
- `astype()` for type conversion
- `pd.to_numeric()` for numeric conversion
- `pd.to_datetime()` for date conversion
- Boolean data type conversion
- Handling invalid values using `errors="coerce"`
- Missing-value detection using `isna()`
- Data type validation

## 💻 Tasks Implemented

### 1. Data Type Inspection
- Display the data types of all columns.
- Inspect dataset information and dimensions.
- Identify columns stored as strings.

### 2. Type Conversion
- Convert customer IDs to integers.
- Convert ages to integers.
- Convert purchase amounts to floating-point numbers.
- Convert membership values to Boolean.
- Convert joining dates to datetime format.

### 3. Handling Invalid Values
- Convert invalid numeric values into missing values.
- Identify invalid or missing values.
- Verify converted data types.

### 4. Data Analysis
- Calculate average customer age.
- Calculate average purchase amount.
- Count members and non-members.
- Validate the final cleaned dataset.

## 🔍 Key Learning
- Correct data types are essential for accurate calculations.
- Numeric values support mathematical operations.
- Boolean values support logical filtering.
- Datetime values enable date-based analysis.
- Invalid values should be handled carefully during conversion.

## 📈 Learning Outcomes
Through this task, I improved my understanding of Pandas data type inspection, type conversion, invalid-value handling, and dataset validation.

## ✅ Conclusion
Appropriate data types improve data consistency and make data processing more reliable. Type conversion is an important step in preparing datasets for analysis and machine learning.

# Day 6 Task: List and Dictionary Comprehensions

## Overview
This task is part of the Veda Technology Data Science Internship[cite: 1]. It focuses on mastering **List and Dictionary Comprehensions**, which are concise Python techniques widely used for data preprocessing and efficient data manipulation.

---

## 1. List Comprehensions
List comprehensions provide a short and elegant way to create lists based on existing iterables.

* **Syntax:** `[expression for item in iterable if condition]`
* **Examples Covered in Notebook:**
  1. Generating squares of numbers from 1 to 10.
  2. Filtering even numbers from a range.
  3. String transformation (converting names to uppercase).
  4. Combined filtering and transformation (squares of even numbers).
  5. Student marks dataset processing (assigning Pass/Fail status based on a condition).

---

## 2. Dictionary Comprehensions
Dictionary comprehensions allow creating dictionaries dynamically using expressions and conditions.

* **Syntax:** `{key_expr: value_expr for item in iterable if condition}`
* **Examples Covered in Notebook:**
  1. Creating a number-to-cube mapping dictionary.
  2. Filtering an existing product price dictionary (filtering items > 500).
  3. Transforming student names and marks into a grade dictionary.

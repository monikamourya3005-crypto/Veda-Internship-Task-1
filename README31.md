# Day 31: Correlation Analysis

## 📌 Project Overview
This project focuses on analyzing relationships between numerical variables using Python, Pandas, Matplotlib, and Seaborn. Correlation analysis helps identify patterns and relationships within datasets.

## 🎯 Objectives
- Calculate correlations between numerical variables.
- Create a correlation matrix.
- Visualize relationships using correlation heatmaps.
- Create scatter plots to analyze variable relationships.
- Interpret strong, moderate, and weak correlations.

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## 📊 Tasks Performed
- Created a sample dataset containing numerical variables.
- Explored the dataset using Pandas.
- Calculated a correlation matrix using `df.corr()`.
- Visualized correlations using a heatmap.
- Created scatter plots for different variable combinations.
- Interpreted positive and negative correlations.
- Analyzed relationships between study hours, marks, sleep hours, and attendance.

## 📚 Key Concepts
- **Correlation:** Measures the relationship between two numerical variables.
- **Positive Correlation:** Variables tend to increase together.
- **Negative Correlation:** One variable tends to decrease as the other increases.
- **Correlation Coefficient:** Ranges from -1 to +1.
- **Correlation Heatmap:** Visual representation of correlations.
- **Scatter Plot:** Displays the relationship between two variables.

## 💡 Conclusion
This task helped me understand how to identify and visualize relationships between numerical variables. Correlation analysis is an important technique in Exploratory Data Analysis (EDA) and Machine Learning.

**Note:** Correlation does not imply causation.

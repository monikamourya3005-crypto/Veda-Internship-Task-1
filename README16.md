# Day 16: Selecting Rows and Columns with `loc[]` and `iloc[]`

## 📌 Project Overview
This task focuses on selecting specific rows and columns from a Pandas DataFrame using `loc[]` and `iloc[]`.

## 🎯 Objective
- Understand label-based data selection using `loc[]`.
- Understand position-based data selection using `iloc[]`.
- Practice selecting individual rows, columns, and multiple records.
- Compare both selection methods.

## 🔍 Difference Between `loc[]` and `iloc[]`

| Feature | `loc[]` | `iloc[]` |
|---|---|---|
| Selection type | Label-based | Position-based |
| Uses | Index and column labels | Integer positions |
| Slice ending | Included for label slices | Excluded for positional slices |
| Conditional filtering | Supported | Usually uses integer positions |
